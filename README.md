# 带键盘事件的计算器（Qt 实验 1）

基于 Qt 6 Widgets 开发的桌面计算器，支持鼠标与键盘两种输入方式，二者复用同一套处理逻辑。

## 功能清单

- 加、减、乘、除四则运算，支持小数
- 退格（⌫）与清除（C）
- 键盘完整操作，鼠标与键盘可混合输入
- 异常输入处理：重复小数点、连续操作符、前导零
- 边界处理：除数为 0、计算后继续输入、连续运算、清除后重新计算

## 环境要求

- Qt 6（开发环境为 Qt 6.9.3 MinGW 64-bit）
- CMake ≥ 3.16，支持 Ninja / MinGW
- Git

## 构建与运行

### 方式一：Qt Creator（推荐）

1. 打开 Qt Creator，选择“文件 → 打开文件或项目”
2. 选择本项目的 `CMakeLists.txt`
3. 选择 MinGW 套件，点击“配置项目”
4. 点击左下角运行按钮（或按 `Ctrl+R`）

### 方式二：命令行

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_PREFIX_PATH=<Qt安装路径>/mingw_64 \
  -DCMAKE_CXX_COMPILER=<MinGW路径>/bin/g++.exe
cmake --build build
```

## 键盘映射

| 键盘按键 | 功能 |
|---|---|
| `0` - `9` | 数字输入 |
| `.`（或 `,`） | 小数点 |
| `+` `-` `*` `/` | 四则运算符 |
| `=` / `Enter` / 小键盘回车 | 计算结果 |
| `Backspace` | 退格 |
| `Esc` / `Delete` / `C` | 清除 |

## 边界测试用例

| 用例 | 输入 | 预期结果 |
|---|---|---|
| 小数运算 | `1.5 + 2.25 =` | `3.75` |
| 重复小数点 | `1.2.3` | 第二个小数点被忽略，显示 `1.23` |
| 连续操作符 | `5 + - 3 =` | 运算符替换为 `−`，结果 `2` |
| 连续运算 | `2 + 3 × 4 =` | 依次得到 `5`、`20` |
| 除数为零 | `6 ÷ 0 =` | 显示“错误：除数不能为 0”，输入锁定 |
| 错误后恢复 | 除零后按 `C` | 回到 `0`，可重新计算 |
| 结果后继续 | `2 + 3 =` 后按 `× 2 =` | 结果 `10` |
| 退格 | 输入 `123` 后按 `⌫` | 变为 `12`，删空回到 `0` |
